## Major Projects

**[TPU-Inspired AI Matrix Multiplication Accelerator](https://github.com/h-kxn/tpu-inspired-ai-matrix-multiplication-accelerator)**
Standard hardware multiplication doesn't scale well as matrix size grows. I designed a systolic array-based multiplier inspired by Google's TPU and applied tiling to handle larger matrices efficiently, built and simulated in Logisim Evolution. The result: higher parallel throughput and reduced redundant memory access.
